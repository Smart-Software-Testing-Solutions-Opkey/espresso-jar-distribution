# espresso-jar-distribution
The executable JAR that reads your config, uploads APKs, books devices, and triggers test execution on the Pcloudy cloud 

# Steps
Step 1: Setup-Download and Unzip the Espresso Starter Pack 
Step 2: Place Both Files in the Same Directory 
Step 3: Configure the config.json File -Open config.json in any text editor and fill in the required values. The file is structured into four sections: Cloud Settings, Test Execution, Application Files, and Test Settings. 
step 4: Execute the JAR from the Command Line
